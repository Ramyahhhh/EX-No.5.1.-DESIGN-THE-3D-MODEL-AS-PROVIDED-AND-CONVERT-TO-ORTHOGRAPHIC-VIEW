# EX No.5.1.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:12-11-26
## REG NO: 26017329
## NAME : M RAMYA



## AIM: 
To create a 2D engineering drawing sheet containing the principal orthographic views of a 3D solid component in Autodesk Fusion 360.


## HARDWARE AND SOFTWARE REQUIREMENTS

• Software. Autodesk Fusion 360 (3D CAD/CAM modeling suite) with an active user account.
• Operating System. Microsoft Windows 10 (64-bit) operating system.
• Memory & Graphics. 16 GB RAM paired with integrated or dedicated graphics supporting 1 GB or more VRAM.
• Internet Connectivity. A stable broadband connection with at least 2.5 Mbps download and 500 Kbps upload speeds for cloud synchronization.
• Peripherals. A standard keyboard, a three-button scroll mouse, and a display monitor.


## PROCEDURE:

## STEP-1:
   Launch Autodesk Fusion 360, navigate to the File menu, and select New Design to open a blank workspace.
## STEP-2: 
   Select Create Sketch on the XY plane, draw the slotted base flange and mounting lugs using Line, Circle, and Trim tools, and click Finish Sketch.

    <img width="287" height="292" alt="image" src="https://github.com/user-attachments/assets/f966946b-d064-42ee-8b5a-5f178ab179c1" />

## STEP-3: 
   Use the Extrude command to convert the base flange sketch into a 3D solid body of the specified thickness.
## STEP-4: 
   Create a new sketch on the top face of the base to draw the central cylindrical hub and tapered support ribs, then Extrude them to the required heights.
## STEP-5:
   Use the Extrude (Cut) and Hole commands to create the central stepped bore, mounting holes, and counterbores, then apply R2 and R12 rounds using the Fillet tool.

   <img width="437" height="540" alt="image" src="https://github.com/user-attachments/assets/5078477d-7245-492f-8fae-0a99b49f31e7" />

## STEP-6:
   Save the 3D model and switch the workspace from Design to Drawing (From Design) to open a 2D drawing sheet.
## STEP-7: 
   Place the Base View (top view) on the sheet, generate the right-side view using Projected View, and create Section A-A, Section B-B, and Section C-C using the Section View tool.
## STEP-8: 
   Add all linear, angular, and radial dimensions using the Dimension tool, verify the layout, and save the final drawing sheet.
